## 1280x720 分辨率适配修订清单（v4 — 保持原始字号版）

**调整策略：** 所有字号保持 1920x1080 原始值不变，仅压缩间距、尺寸和边距，使内容在 1280x720 视图中尽量饱满展示。

---

### 一、全局参数变更

| 项目 | 原值 (1920x1080) | 新值 (1280x720) | 说明 |
|------|-------------------|------------------|------|
| 视口 (viewport) | 1920 x 1080 | 1280 x 720 | meta 标签 |
| 基准字号 (html) | 18px | **18px（不变）** | 全部 font-size 保持原值 |
| Slide 内边距 | 80px 100px 60px | 40px 40px 30px | 大幅收紧，最大化内容区 |
| 可用内容宽度 | 1720px | **1200px** | 1280 - 40 - 40 |
| 可用内容高度 | 940px | **650px** | 720 - 40 - 30 |
| 导航栏位置 | bottom:28px right:40px | bottom:8px right:16px | 贴近右下角 |

### 二、间距与尺寸缩放规则

所有非字号的 px 值（padding、margin、gap、width、height、border-radius、box-shadow 偏移等）统一乘以 **0.75** 系数。典型变化举例：

| 元素 | 原值 | 新值 |
|------|------|------|
| --radius | 16px | 12px |
| --radius-sm | 10px | 8px |
| --shadow | 0 4px 24px | 0 3px 18px |
| .sec-title margin-bottom | 12px | 9px |
| .sec-sub margin-bottom | 40px | 30px |
| .two-col gap | 36px | 27px |
| .three-col gap | 32px | 24px |
| .four-col gap | 28px | 21px |
| .scene-card padding | 24px | 18px |
| .agent-card padding | 40px 32px | 30px 24px |
| .stat-card padding | 36px 28px | 27px 21px |
| .icon-circle 尺寸 | 68px | 51px |
| .agent-icon 尺寸 | 88px | 66px |
| .blob 典型尺寸 | 400px | 300px |

### 七、注意事项

1. 由于字号未缩小，在 1280px 宽度下文字密度会比原 1920 版本略高，阅读体验更接近桌面端正常浏览效果
2. 间距压缩后卡片之间的呼吸感略有减少，但内容完整性未受影响
3. 如需进一步微调某一页的间距，可直接修改对应 slide 内的行内 style 值
4. 建议用浏览器以 1280x720 窗口尺寸全屏预览，逐页确认布局效果
