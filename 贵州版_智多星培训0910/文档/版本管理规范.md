# 贵州版 · 通联智多星培训材料 · 版本管理规范

> 本文件定义「面向**贵州分公司**」这份培训材料（简称**贵州版**）的归档规范与工作流程。
> 广东版规范见 `广东版_智多星培训0903v1/文档/版本管理规范.md`。

## 一、目录结构

```
贵州版_智多星培训0910/
├── 演示稿/                    ★【产出】演示文件在这里
│   ├── 贵州版_演示稿.html      # HTML 演示稿（直接双击打开）
│   └── 贵州版_讲稿.md          # 配套讲稿
├── 素材/                       # 图片素材（演示稿用 ../素材/ 引用）
├── 工具/                       # 一次性脚本（非产出物）
├── 文档/                       # 过程文档
│   ├── 版本管理规范.md          # 本文件
│   ├── 版本记录.md              # 总索引
│   ├── 核心大纲.md              # 核心大纲（滚动更新至最新版）
│   └── 角色设计方案.md          # 角色设计输入文档（方向已调整为按场景，仅留档）
└── 归档/
    ├── v<日期>_<版本名>/         # 每个定稿版本一个快照目录
    │   ├── 培训材料.html
    │   ├── 培训讲稿.md
    │   ├── 核心大纲.md
    │   └── 修订记录.md
    └── 过程稿/                  # 逐页修改过程中的阶段性文件
```

> 广东版与贵州版**结构完全一致**，仅最外层目录名不同，便于对照维护。

---

## 二、每次版本定稿后的归档动作（标准流程）

1. **快照演示稿** → `归档/v<日期>_<版本名>/培训材料.html`
2. **快照讲稿** → 同目录 `培训讲稿.md`
3. **写修订记录** → 同目录 `修订记录.md`（逐条说明页面、内容、原因）
4. **更新核心大纲** → 同目录 `核心大纲.md`，并同步 `文档/核心大纲.md`
5. **更新总索引** → `文档/版本记录.md` 追加版本行与修订明细
6. **保留工作区** → `演示稿/` 继续作为下一轮迭代工作区

## 三、命名规范

> **核心规则：演示文件带「分支前缀」，便于在编辑器标签页 / 文件管理器中一眼区分是哪一版；
> 归档快照不带前缀（已位于带日期的版本目录内，天然唯一）。**

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 项目目录 | `<分支>_智多星培训<日期>` | `贵州版_智多星培训0910` |
| 演示稿 | `演示稿/<分支>_演示稿.html` | `演示稿/贵州版_演示稿.html` |
| 讲稿 | `演示稿/<分支>_讲稿.md` | `演示稿/贵州版_讲稿.md` |
| 版本目录 | `归档/v<YYYYMMDD>_<版本名>` | `归档/v20260910_初版框架` |
| 归档文件 | `<类型>.<ext>`（在版本目录内） | `培训材料.html` |

> 同一天多次定稿时，在版本名后追加序号，如 `v20260910_内容精简2`。

## 四、与广东版的关系

> 🔒 **广东版已冻结**：`广东版_智多星培训0903v1/` 已定稿归档，**禁止任何修改**（演示稿 / 讲稿 / 文档 / 素材 / 归档快照一律不得增删改）。
> 仅允许只读使用：查看、参考、复制素材到贵州版。所有后续迭代只在贵州版内进行。

- **独立项目**：本份材料面向贵州分公司，拥有独立的工作区与版本归档，不覆盖广东版。
- **素材复用**：需要广东版的图片素材时，从 `广东版_智多星培训0903v1/素材/` 复制到本目录 `素材/`，
  避免跨目录引用导致的路径失效。
- **结构参考**：广东版结构见 `广东版_智多星培训0903v1/文档/核心大纲.md`。

## 五、版本还原方法

1. 从 `归档/v<日期>_<版本名>/` 中取出 `培训材料.html`
2. 复制到 `演示稿/贵州版_演示稿.html`
3. 同理取出 `培训讲稿.md` 替换 `演示稿/贵州版_讲稿.md`

> 注意：HTML 中的图片引用为相对路径 `../素材/`（归档版为 `../../素材/`），还原后需保证 `素材/` 存在。
