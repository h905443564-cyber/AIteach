## 三、本版核心调整方向（相较广东版）

> **重构原则：融合重组，非推翻重来。** 以广东版 19 页内容为基础，保留高价值内容，仅调整组织方式与叙事包装。

1. **引入数字人 IP「发仔」**：强化"由发仔提供服务，智多星只是 AI 底座"的底层概念（保留原版底座叙事，二者承接）
2. **内容组织改为「按角色的场景打包」**：原有功能不删减，仅按角色重新归类打包，解决"从智能体到用户"的中间断层
3. **新增「局限性与迭代计划」**：坦诚说明边界 + 后续路线 + 开放 MCP 共创（复用原版「开放生态」内容）

**页面固定逻辑（三段式）**：演示前铺垫清晰 → 演示中聚焦场景 → 演示后说明局限

**三阶段结构**：
- 阶段一：智能体工厂基础能力 + 智多星平台标识（强化入口感知）
- 阶段二：按角色展示已落地场景方案与具象应用 + 开放 MCP 邀约共创
- 阶段三：点明现阶段局限性与后续迭代计划

> 详细结构见 `贵州版_核心大纲.md`。
