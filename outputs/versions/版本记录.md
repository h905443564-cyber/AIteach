   - 研发智擎：独立紫色渐变卡片，虚线边框 + "即将推出"标签

4. **CSS样式更新**
   - 新增`.scene-card-header`类（flex布局对齐序号和标题）
   - `.scene-card .num`添加`flex-shrink:0`防止变形
